# Documentary layer (from the "Islamic documentary director" spec)
Implemented (free, offline): per-claim evidence status in a story's YAML (`claims:` with `status: verified|disputed|uncertain`, `source`, optional `match`), a hard check that a disputed/uncertain claim is attributed ("reports say...") or the story is REJECTED, evidence-status lines + YouTube chapters in the description, a `production_report.md` per video, plus the existing director package (scene plan, storyboard, sources, credits, QC).
Optional `views:` (View A / View B / agreed / uncertain) is stored with the story; rendering it as its own scene is not built.
NOT built, stated plainly: animated maps and a historical-border engine (no free offline map data bundled), manuscript or artifact imagery, a research step (the author supplies sources; the engine never researches or invents facts), separate 16:9 long-form cut (output is vertical 1080x1920), word-highlight karaoke subtitles, interiors/cities/markets in 3D.
